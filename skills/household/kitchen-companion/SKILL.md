# Household Kitchen Companion

Use this skill when household members ask for meal ideas, recipes, recipe storage, or shopping-list help.

## Meal ideas and saved recipes

- Offer two or three ideas when asked, adapting to known preferences, allergies, diets, ingredients, and time constraints.
- Search the local notebook before repeating or presenting a saved recipe. When the CLI is installed, run kitchen-companion recipe search with the query and configured data directory. Otherwise, use local file tools to read recipes.json.
- Save a recipe only after an explicit request. When the CLI is installed, run kitchen-companion recipe add with the title, ingredients, method, and configured data directory.
- If the CLI is unavailable but local file tools work, read recipes.json first and append a JSON object with a unique id, title, and body. Create the file as a JSON list when it does not exist. Preserve the other entries.
- Never interpolate member-provided text into an unquoted shell command. If command-line argument quoting is uncertain, use the local file tools instead.
- Respect declared allergies carefully and ask for clarification when an ingredient or cross-contact risk is unclear.
- Include a vegetarian alternative when suggesting a meal that contains meat or fish.
- Do not create or send a weekly menu unless asked.

## Shopping list

- Read shopping.json or run kitchen-companion shopping list with the configured data directory before reporting the current list.
- Add only items the user asks to add. Use kitchen-companion shopping add when available; otherwise append to the JSON list, avoiding a case-insensitive duplicate.
- Remove only the specific item a user asks to remove. Use kitchen-companion shopping remove when available; otherwise remove the matching string case-insensitively from the local JSON list.
- Confirm changes only after the helper or file write succeeds. Do not silently clear the list or remove other items.

## Discord channel mapping

Read the configured state file for the server and channel IDs. It is generated by kitchen-companion discord setup; it contains IDs only. Never guess IDs or hard-code them. If the file is absent, explain that the household can run the setup command. The bootstrap creates channels; it does not configure a Discord bot gateway or send messages by itself.

## Optional short-form video extraction

Only attempt this when a separate extractor and its user-provided dependencies are installed. If that capability is absent or fails, say so briefly and continue with the available recipe and meal-planning support. Never invent extracted ingredients or instructions.

## Language example

English is the public default. A household can configure French, for example, with language set to French. Reply in that language unless the user requests another one.
